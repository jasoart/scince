## 本次補課與後續驗收原則

採「官方內容索引 → 對應課程 → 正文教學證據 → 例題／原創練習」逐層核對。學習內容一條可能需要多課，一課也可能教數條；不以四科課程數相同作為補課目標。

每個範圍至少須能找到：明確的學習目標、對應概念的獨立解釋、模型或公式的條件與限制、例證或解題示範，以及有解釋的自我檢核。科學史內容必須交代問題、證據與解釋變化；應用內容必須有具體情境及判讀；探究內容必須交代記錄、證據與限制。只增加代碼、標題、人名或例子清單不通過實質審查。

技術檢查可驗證 177 個索引不重複、163 個四科代碼與來源一致、頁碼正確、課程識別碼存在及課程資料結構完整。這些檢查不能自動證明每段科學解釋完全正確，也不能代替教師審稿或學習成效評量。課程追溯對照為本站編輯資料，沒有大考中心或其他機構的外部認證。

保持使用者要求：網站提供原創教學、例題與練習，不顯示或重新加入歷屆試題。
